## ✦ About the Blog

This is the **source repository for Fenghui's personal blog**. Launched on **June 15, 2026**, it documents my journey through frontend development, experiments with websites and services, and everyday experiences.

Built on the [Shirone](https://github.com/LyraVoid/Shirone) theme with **Material 3 Expressive** design, it offers a quiet space for writing, hobbies, and life through soft dynamic colors and light and dark themes.
